# Helper práctico 0 — Prepararse para la materia

Fuente: [Clase 0 - Practica.pptx](../enunciados/Clase%200%20-%20Practica.pptx), diapositivas 4–11.

Esta presentación es introductoria: no contiene una guía de ejercicios para resolver.

## Qué presenta

- Paradigma orientado a objetos con Dolphin Smalltalk.
- Paradigma funcional con Haskell.
- Paradigma lógico con Prolog.
- Recomendación de repasar dominio, codominio y recursión.

La diapositiva 6 enumera un parcial práctico, un integrador y notas mayores a 4 en cada tema para aprobar cursada. Para promoción menciona parcial teórico, notas mayores a 6 en cada tema y hasta 4 faltas. Conservá esas expresiones tal como aparecen y confirmá el régimen vigente con la cátedra.

## Receta para arrancar

1. Conseguir la imagen o versión de Dolphin indicada por la cátedra y comprobar que todos los integrantes puedan abrirla.
2. Ubicar Workspace, Transcript, Browser e Inspector en el entorno.
3. Evaluar `'hola' size` y `4 + 2 * 5`; esperar `4` y `30`.
4. Guardar una primera práctica y comprobar cómo recuperarla en otra sesión.
5. Leer [introducción a POO](../../teoria/apuntes/01-poo-introduccion-helper.md) y seguir con el [helper de clase 1](clase-01-modelado-helper.md).
6. Antes del integrador, acordar cómo exportar/importar código y cómo compartir cambios entre las imágenes de Dolphin del grupo.

## Mini repaso previo

- Explicá con tus palabras entrada, salida, dominio y codominio de una función.
- En una definición recursiva, identificá el caso base y cómo cada paso se acerca a él.
- Elegí una entidad cotidiana y separá sus datos de sus acciones.

Para el trabajo grupal, cada persona debe poder abrir el entorno y explicar esos primeros ejemplos. Registrar problemas de instalación temprano evita que solo una persona pueda ejecutar el proyecto.
